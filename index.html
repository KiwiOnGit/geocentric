Geocentric

A local-first AI project that combines from-scratch language model training, collaborative Mac/Linux compute, a Python web service, and a native macOS agent workspace that can create files, review plans, show diffs, run commands, search the web, and keep project state.

All Areas

Geocentric is not one narrow app. It is a toolkit for learning, training, serving, and using local AI systems from one repository.

Training Core

Train a tokenizer, pretrain a decoder-only Transformer, and run supervised fine-tuning from your own datasets.

Collaborative Compute

Split training across Apple Silicon and Linux CUDA machines through the socket-based pipeline bridge.

Server and API

Serve the model through the web chat UI, local endpoints, and OpenAI-style completion routes.

Desktop Agent

Use the macOS app for chat history, model switching, workspace file tools, plan approval, diff rollback, scheduled tasks, and web-search-backed runs.

Workspace Tools

Agent mode can write files, read files, run commands, inspect processes, capture local web views, stage multi-file context, and update roadmaps.

Tutorial

The shortest path is the wizard. It asks what you want to run and tunes settings for Apple Silicon, CUDA, or CPU.

Install dependencies

Create a Python virtual environment, upgrade pip, and install `requirements.txt`.

Train or load a model

Run the wizard for tokenizer, pretraining, SFT, or the complete pipeline.

Serve locally

Start the server on `127.0.0.1:8000` and open the chat UI or API clients.

Use the desktop app

Build the macOS app DMG, choose a project folder, select an Ollama model, review the plan, then let Agent mode use tools for real tasks.

How To

Copy the command path that matches what you are doing today.

Fast local training

python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
python -m geocentric.cli wizard

Serve the web UI

python -m geocentric.cli serve \
  --model_dir runs/geocentric2_1 \
  --host 127.0.0.1 \
  --port 8000

Build the Mac app

cd mac_app
./build_pkg.sh
open Geocentric.app

Collaborative training

python -m geocentric.cli pipeline-train \
  --master_ip 192.168.1.30 \
  --master_port 29500 \
  --rank 0 \
  --world_size 2

Desktop Agent

The native app is designed around one model chooser, a left drawer, an Antigravity-style right Agent Side Panel, clear service status, and tool-first behavior for requests that need real workspace action.

Agent behavior

Explicit file, command, project, debugging, scheduled-task, and web-current requests are routed to the local agent service. The first status defines the objective, then the agent uses tools and reports progress. Complex file-changing work pauses at `Implementation Plan.md` until you accept or deny it.

Model behavior

Simple conversation stays fast. The single toolbar model menu refreshes, downloads, manages, and switches Ollama models without duplicating controls.

Visible code changes

File edits are captured as split red/green diffs in the Agent Side Panel, with per-file Approve and Rollback actions.

Context and telemetry

A context ring tracks prompt-envelope usage, pinned files appear below the composer, and the telemetry HUD reports local CPU, memory, disk, and GPU availability.

Why

Geocentric exists to make local AI understandable and useful. It keeps the training loop visible, the runtime local, and the agent tools practical enough to create real project artifacts.

Learn the whole stack

Tokenizer, model, training loop, server, UI, and desktop packaging are all present.

Stay local first

Run on your own Mac, Linux machine, local network, or direct cable setup.

Make the agent useful

Tool use is treated as the point: create files, run tests, search when current facts matter, and keep moving.

FAQ

Common questions about what Geocentric is and how the pieces fit together.

Is Geocentric a pretrained model?

No. The training stack is designed for from-scratch experiments. The desktop app can also use installed Ollama models for practical local chat and agent work.

Why does the desktop app need a project folder?

Workspace tools need a safe, explicit place to read, write, and test files. Choose a folder before asking for file creation or edits.

When should web search run?

Use it for explicit search requests or current information such as news, latest releases, recent events, and today-specific facts.

Can it train across two computers?

Yes. The collaborative training path supports Mac and Linux workers over a local network, with direct cable setup available for faster dedicated links.

Where are detailed commands?

Use USAGE_GUIDE.md for full commands and DATA_FORMAT.md for accepted training and workspace data formats.
